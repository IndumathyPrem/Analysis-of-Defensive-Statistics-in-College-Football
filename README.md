# Analysis of Defensive Statistics in College Football

## Project Overview

This project analyzes defensive statistics in college football using Python, Pandas, Seaborn, Matplotlib, Power BI, and Streamlit.

The objective is to identify defensive performance patterns, compare teams, analyze trends, and build interactive dashboards for data-driven decision-making.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Power BI

## Dataset

College Football Defensive Statistics Dataset covering seasons from 2022–2025.

Key metrics include:

* Tackles
* Solo Tackles
* Sacks
* Interceptions
* Forced Fumbles
* Team Performance
* Home/Away Venue

## Key Insights

* Average tackles per game ≈ 2.09
* Home and away games are nearly balanced
* Total tackles and solo tackles show strong correlation
* Top teams consistently outperform the average
* Defensive activity varies significantly across players

## Recommendations

* Improve tackling efficiency
* Monitor defensive pressure metrics
* Use multiple defensive KPIs for evaluation
* Track season-over-season performance
